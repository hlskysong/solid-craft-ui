# 04 组件范围

> 状态：v0.3（决策落地）· 2026-11-05  
> 目标：先覆盖企业内部中后台 80% 的页面，再扩展业务组件。**不追求 AntD 全量对齐**。

---

## 1. 优先级定义

| 优先级 | 含义 | 交付节点 |
| --- | --- | --- |
| **P0** | 试点应用无法缺少；MVP 必须完成 | v0.1 / MVP |
| **P1** | v1.0 核心能力；常见业务页面需要 | v1.0 |
| **P2** | 业务增强 / 特定场景；v1.x 迭代 | v1.x |
| **P3** | 不自研，提供集成方案 | 文档 / 示例 |

复杂度：**S**（1–3 天）、**M**（1–2 周）、**L**（2–4 周）、**XL**（4 周以上，需拆分）。

## 3. MVP（v0.1）范围

MVP 目标：**让 1–2 个试点业务系统能完整开发一个典型 CRUD 页面**（列表 + 查询 + 表单 + 详情 + 弹窗 + 反馈）。

### 3.1 P0 组件（33 个）

**基础 / 布局（9）**  
`ConfigProvider`、`App`、`Button`、`Icon`、`Typography`、`Space`、`Divider`、`Layout`、`Grid`

**表单（9）**  
`Input`、`InputNumber`、`Checkbox`、`Radio`、`Switch`、`Select`、`Form`、`DatePicker`（基础）、`Upload`（基础）

**数据（8）**  
`Table`（基础）、`Pagination`、`Card`、`Tag`、`Tabs`、`Empty`、`Skeleton`、`Descriptions`（详情页需要，提前到 P0）

**反馈（7）**  
`Alert`、`Message`、`Modal`、`Drawer`、`Tooltip`、`Popconfirm`、`Spin`

> 合计 33 个。`Table` / `Form` / `Select` / `DatePicker` 是四个高风险项，必须在 Phase 0 做 Spike，必要时调整 MVP 边界。

### 3.2 MVP 明确不做

- Table 虚拟滚动、固定列、树形数据、可编辑单元格（v1.0）。
- DatePicker 范围选择、时间选择、时区（v1.0；试点若强依赖，提前）。
- Form.List、dependencies、shouldUpdate（v1.0）。
- 级联 / 树选择 / 穿梭框（v1.0）。
- Menu / Steps / Breadcrumb（v1.0；试点布局可先用简单自定义）。
- 暗色/密度/RTL 的完整视觉回归（**v0.2 分档**：MVP 只出 light/ltr/default 基线，v1.0 补齐四套）。
- **SSR 全矩阵 / 流式渲染 / Portal 细则**：MVP 只验 `renderToString` + hydration 单档冒烟（light / ltr / default）与 `"solid"` 双构建；暗色 / 紧凑 / RTL 的 SSR 回归、流式渲染、Portal 细则属 v1.0。
- Table 虚拟滚动的 60fps 性能验收（Phase 5 功能落地时验收）。

### 3.3 MVP 验收

- 试点应用能完成：登录后列表页、查询表单、新增/编辑弹窗、详情页、删除确认、成功/失败提示。
- P0 组件文档齐全，每个至少 3 个 Demo。
- P0 组件通过 axe 扫描与键盘测试；视觉基线按 light/ltr/default 分档（dark/compact/rtl 属 v1.0）。
- 构建产物在 Vite / Webpack 5 / Rspack 三端可用；`"solid"` 条件导出可解析；`examples/solid-start` 通过 SSR 渲染 + hydration 冒烟（无 console warning）。
- 包体积预算达标。

## 5. 复杂组件拆解

### 5.1 Table

**P0 基础能力**

- 列配置：`title`、`dataIndex`、`width`、`align`、`render`、`fixed`（基础）。
- 数据：`data`、`rowKey`、`loading`、`empty`。
- 排序：单列/多列、受控/非受控。
- 筛选：内置筛选下拉、自定义 `filterDropdown`。
- 选择：checkbox / radio、全选、禁用行、受控 `selectedRowKeys`。
- 分页：客户端/服务端、与 `Pagination` 集成。
- 尺寸/边框/粘性表头。
- 事件：统一 `onChange({ pagination, filters, sorter })`，对齐 AntD 使用习惯；`Pagination` 组件自身仍提供 `onChange`。

**密度与内距目标**（对齐 03 §1「高效优先」；不沿用 AntD 默认 16/16）

- `cellPaddingBlock` / `cellPaddingInline`：默认 12 / 12（高密度档），可选 16 / 16（舒适）、8 / 8（紧凑）。
- 字号取 `--ui-font-size-md`（14px），表头与正文同档，不靠缩字号表达层级。

**P1 高级能力**

- 虚拟滚动（固定行高优先，动态行高后续）。
- 固定列（左/右、阴影、同步滚动）。
- 分组表头、展开行、树形数据。
- 列宽拖拽、列显示/排序/固定设置。
- 汇总行、可编辑单元格、行拖拽排序。
- 空/加载骨架、密度适配。

**P2**

- ProTable：查询表单、工具栏、批量操作、请求函数、列持久化、导出。

**关键风险**

- 虚拟滚动 + 固定列 + 树形 + 动态行高组合复杂；必须分阶段交付。
- 受控状态与内部状态混用容易出 bug；统一用 `useTableEngine` 管理。
- 服务端分页/排序/筛选的参数协议要定清楚，避免每个业务自己拼。

### 5.2 Form

**P0**

- `Form` / `Form.Item` / `useForm`。
- `initialValues`、`onFinish`、`onFinishFailed`、`validateFields`、`resetFields`、`setFieldsValue`、`getFieldsValue`。
- 校验：required、min/max、pattern、type、自定义同步/异步 validator。
- 布局：horizontal / vertical / inline；label 宽度、冒号、必填标记。
- 错误展示、滚动到第一个错误、`aria-invalid` / `aria-describedby`。

**P1**

- `Form.List`、`dependencies`、`shouldUpdate`、嵌套路径。
- Zod / Valibot resolver 适配。
- 字段级订阅与性能优化。
- `preserve`、`validateTrigger`、`getValueFromEvent`、`normalize`。

**关键设计**

- `Form.Item` 通过 `FieldContext` 向子控件注入 `value` / `onChange` / `status` / `id` / `aria-*`；其中 `value` / `status` / `disabled` **必须是 getter**（`() => T`），按 [02 §6 响应式契约](./02-架构设计.md#6-公共-api-约定) 执行，否则 Solid 下字段值不会更新。
- 所有表单控件必须实现 `useFormField` 协议；这是组件库内部契约。
- 受控组件与 Form 的受控状态要区分：Form 是唯一数据源，控件不保留重复状态。

### 5.3 Select

**P0**

- 单选/多选、搜索、清除、禁用、loading、空状态。
- `options` 扁平结构；`fieldNames` 支持自定义 `label` / `value` / `disabled` 字段；`value` / `onChange`；`labelInValue` 可选。
- 键盘：上下、Enter、Esc、Tab、Home/End、typeahead。
- 弹层定位（Floating UI）、宽度自适应、滚动。

**P1**

- 远程搜索（防抖、取消请求）、分组、自定义 `renderOption` / `renderTag`。
- 虚拟滚动（大列表）、`maxTagCount`、`tagRender`。
- 与 Form 集成、`status`、`allowClear`。

**P2**

- Cascader / TreeSelect 独立组件；Select 不承担树形职责。

### 5.4 DatePicker

**P0**

- 单选日期、`min` / `max`、`disabledDate`、`format`、清除、今天。
- 中文 locale、周一/周日首日、键盘导航。
- 输入框手动输入与解析；非法输入恢复。
- SSR 安全（不默认取当前时间作为初始值）。

**P1**

- RangePicker、快捷选项（今天/近 7 天/本月/上月）。
- `showTime`、`TimePicker`、时区、月份/年份选择。
- 多选日期、禁用时间、自定义单元格。

**P2**

- Calendar 独立组件、季度选择、复杂业务日历。

**关键风险**

- 日期解析/格式化不要自己造完整轮子；用 `@internationalized/date` + `Intl`。
- 受控值与内部输入字符串的同步是 bug 高发区；需要明确的 `editing` 状态机。
- 范围选择的 hover 预览、键盘、焦点管理复杂，单独排期。

### 5.5 Upload

**P0**

- 点击/拖拽上传、多文件、`accept`、`maxSize`、`maxCount`。
- `beforeUpload`（返回 false / Promise）、`customRequest`、进度、取消、删除、重试。
- 文件列表展示、错误状态。

**P1**

- 图片预览、粘贴上传、目录上传、拖拽排序。
- 分片上传、断点续传、OSS/S3 直传：通过 `customRequest` 文档 + 示例，不内置云厂商 SDK。
- 与 Form 集成（`fileList` 作为 value）。

**P2**

- 病毒扫描、图片压缩、水印等业务能力，由业务层实现。

## 6. API 示例

### 6.1 Button

```tsx
import { Plus } from '@ui-design/icons';

<Button
  variant="solid"
  color="primary"
  size="medium"
  loading={saving}
  icon={<Plus />}
  onClick={handleSave}
>
  保存
</Button>

<Button variant="text" color="danger" disabled>
  删除
</Button>
```

> `color` 默认 `primary`（v0.3 / Q16 已定），主按钮可省略；示例保留显式写法便于对照。`variant` 默认 `solid`、`size` 默认 `medium`。

### 6.2 Select

```tsx
interface User {
  id: string;
  name: string;
}

<Select<User>
  options={users}
  value={userId()}
  onChange={(id, option) => setUserId(id)}
  fieldNames={{ label: 'name', value: 'id' }}
  searchable
  clearable
  placeholder="请选择用户"
/>;
```

### 6.3 Form

```tsx
interface Model {
  name: string;
  department: string;
  date: Date | null;
}

const [form] = useForm<Model>();

<Form
  form={form}
  layout="vertical"
  initialValues={{ name: '', department: '', date: null }}
  onFinish={(values) => save(values)}
>
  <Form.Item
    name="name"
    label="姓名"
    rules={[{ required: true, message: '请输入姓名' }]}
  >
    <Input placeholder="请输入" />
  </Form.Item>

  <Form.Item
    name="department"
    label="部门"
    rules={[{ required: true, message: '请选择部门' }]}
  >
    <Select options={departments} />
  </Form.Item>

  <Form.Item name="date" label="入职日期">
    <DatePicker />
  </Form.Item>

  <Button htmlType="submit" variant="solid" color="primary">
    提交
  </Button>
</Form>;
```

### 6.4 Table

```tsx
interface Row {
  id: string;
  name: string;
  status: 'active' | 'disabled';
  createdAt: string;
}

const columns: TableColumn<Row>[] = [
  { title: '姓名', dataIndex: 'name', width: 160 },
  { title: '状态', dataIndex: 'status', render: (v) => <Tag>{v}</Tag> },
  { title: '创建时间', dataIndex: 'createdAt', sorter: true },
  { title: '操作', render: (_, row) => <Button variant="link" onClick={() => edit(row)}>编辑</Button> },
];

// 响应式契约：props 一律传值（调用 accessor），不直接传 signal 函数
const [current, setCurrent] = createSignal(1);
const [pageSize, setPageSize] = createSignal(20);
const [total, setTotal] = createSignal(0);
const [selectedRowKeys, setSelectedRowKeys] = createSignal<string[]>([]);

<Table<Row>
  columns={columns}
  data={rows()}
  rowKey="id"
  loading={loading()}
  rowSelection={{ selectedRowKeys: selectedRowKeys(), onChange: setSelectedRowKeys }}
  pagination={{ current: current(), pageSize: pageSize(), total: total() }}
  onChange={({ pagination, filters, sorter }) => {
    setCurrent(pagination.current);
    setFilters(filters);
    setSorter(sorter);
  }}
/>;
```

## 7. 组件文件模板

```text
components/button/
├─ Button.tsx          # 实现
├─ types.ts            # 公共 Props / 类型
├─ button.scss         # 样式（BEM）
├─ index.ts            # 导出（组件 + 类型）
├─ demos/
│  ├─ basic.tsx
│  ├─ variants.tsx
│  ├─ sizes.tsx
│  └─ loading.tsx
└─ __tests__/
   ├─ Button.test.tsx
   └─ Button.keyboard.test.tsx
```

约定：

- 组件使用**命名导出**，不使用 default export。
- `index.ts` 只导出公共 API，不导出内部 hooks / 常量。
- `types.ts` 中公共类型加 JSDoc；`@default` 用于文档生成。
- Demo 文件使用 default export + `demo` 元数据。
- 测试文件与组件同名，放在 `__tests__`。

## 8. Definition of Done（组件完成标准）

每个组件进入 `main` 前必须满足：

### API

- [ ] Props 设计评审通过；命名符合统一约定。
- [ ] 受控/非受控行为完整；`value` / `defaultValue` / `onChange` 一致。
- [ ] `ref` 可用；`class` / `style` 正确合并。
- [ ] 泛型（如需要）不泄漏内部类型；无 `any`。
- [ ] 公共类型有 JSDoc 与默认值说明。

### 视觉

- [ ] 使用 token，无硬编码颜色/间距。
- [ ] 视觉基线按版本分档：MVP = light / ltr / default；dark / compact / RTL 为 v1.0 门槛。
- [ ] 禁用、加载、错误、空状态齐全。
- [ ] 与 TDesign/AntD/Semi 参考及文档站 Demo 一致；差异已在 `reference/design-baseline/compare.json` 记录并给出判定（刻意偏离须附依据）。

### 无障碍

- [ ] 键盘可完成核心操作；焦点顺序合理。
- [ ] ARIA 属性正确；图标按钮有 `aria-label`。
- [ ] axe 扫描无 serious / critical。
- [ ] 表单错误可被屏幕阅读器播报。
- [ ] 对比度达标。

### 行为与边界

- [ ] 模块顶层无 `window` 访问（SSR-safe 编码）；`renderToString` 与 hydration 冒烟通过（**MVP 验收项**，v0.3 / ADR-018）。
- [ ] 长文本、超长数字、窄容器、空数据不崩。
- [ ] 异步场景可取消 / 可重试。
- [ ] 卸载时清理监听与定时器。
- [ ] 与 Form / ConfigProvider / 微前端容器集成正常。

### 测试

- [ ] 单元测试覆盖核心行为、受控/非受控、事件、ref。
- [ ] 键盘测试覆盖关键路径。
- [ ] Playwright 视觉回归基线。
- [ ] 消费方冒烟（Vite / Webpack / Rspack）通过；`"solid"` 条件导出可解析；SolidStart 构建 + SSR 渲染 + hydration 冒烟通过。

### 文档

- [ ] 至少 3 个 Demo（基础、变体、边界）。
- [ ] API 表自动生成 + 手工补充说明。
- [ ] 设计指南 / 使用建议 / 常见问题。
- [ ] 变更记录（Changeset）。

### 质量门禁

- [ ] `lint` / `typecheck` / `test` / `build` 通过。
- [ ] 包体积在预算内。
- [ ] `publint` / `attw` 通过。
- [ ] 无 console warning（生产构建）。

## 10. 组件命名速查

| 类别 | 命名 |
| --- | --- |
| 组件 | PascalCase：`Button`、`DatePicker`、`ConfigProvider` |
| 子组件 | `Form.Item`、`Form.List`、`DatePicker.RangePicker` |
| Props 类型 | `ButtonProps`、`TableColumn<T>`、`SelectOption<T>` |
| 事件 | `onChange`、`onOpenChange`、`onFinish`、`onConfirm` |
| 尺寸 | `small` / `medium` / `large`（唯一口径，禁止 `sm` / `md`） |
| 变体 | `solid` / `outline` / `dashed` / `text` / `link` |
| 颜色 | `primary` / `neutral` / `success` / `warning` / `danger` |
| 状态 | `error` / `warning` / `success` |
| CSS 类 | `.ui-button`、`.ui-button__icon`（BEM 只用于静态结构）；变体 / 状态用 `data-variant` / `data-color` / `data-size` |
| data 属性 | `data-size`、`data-variant`、`data-state`、`data-disabled` |
